# My DSA Learning Journey

This repository is a collection of the algorithms, data structures, practice problems, notes, and implementations **I built while learning Data Structures and Algorithms (DSA)**.

I created these alongside my learning journey to understand the fundamentals by writing, testing, and improving the concepts myself. The repository reflects my progress over time, from basic programming and patterns to advanced data structures and graph algorithms.

## Repository Structure

| Folder / File | Topics |
| --- | --- |
| `.vscode/` | Early practice programs, lectures, patterns, arrays, sorting, strings, pointers, and bit manipulation |
| `restared/` | Recursion, merge sort, quick sort, and recursive problem solving |
| `Linklist/` | Singly linked lists, doubly linked lists, and circular linked lists |
| `stack/` | Stack implementations and stack-based practice |
| `queues/` | Queue and deque implementations |
| `BinaryTree/` | Binary tree creation and traversals |
| `BST/` | Binary search tree implementation |
| `HEAP/` | Heap implementation and heap-related practice |
| `GRAPHS/` | BFS, DFS, cycle detection, shortest paths, MSTs, and topological sorting |
| `DP/` | Dynamic programming practice |

## Highlights

Some of the algorithms and concepts implemented here include:

- Linear search and binary search
- Bubble sort, selection sort, insertion sort, merge sort, and quick sort
- Recursion-based solutions
- BFS and DFS
- Cycle detection
- Dijkstra's algorithm
- Prim's algorithm
- Kruskal's algorithm using Union-Find
- Topological sort using DFS and Kahn's algorithm
- Morris traversal
- Linked list operations
- Stack, queue, deque, and heap implementations
- Bit manipulation and number conversion problems

## Learning Philosophy

The goal of this repository is not just to collect solutions. It is a record of learning DSA by:

1. Understanding the concept.
2. Implementing it from scratch.
3. Running and testing the implementation.
4. Practicing variations of the problem.
5. Revisiting the code to improve my understanding.

The code may vary in style and complexity because it was written at different stages of my learning journey. **That is what makes this repository a personal record of my progress.**
